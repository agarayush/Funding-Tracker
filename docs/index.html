How to get a GitHub token (one-time setup)
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Under Repository access, choose Only select repositories → Funding-Tracker.
  3. Under Permissions → Repository permissions, set Actions to Read and write. Nothing else is needed.
  4. Paste the token here. It is sent only to api.github.com, and is stored only in this browser if you tick “Remember”.

No token? Click “Or start it on GitHub instead”, press Run workflow, and enter the From and To dates shown above.
