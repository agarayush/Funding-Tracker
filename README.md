# India Funding Tracker

A weekly tracker of Indian startup funding rounds, scraped from
[VIE Stories](https://viestories.com/funding-alert) and [YourStory](https://yourstory.com/category/funding),
published as a static website on GitHub Pages.

For every deal it records: **date, company, company brief, sector, sub-sector, round, cheque size
(as written, plus USD and INR crore), lead and other investors, city, use of funds, and source links**.
Each sector gets an AI-written **brief, India-specific tailwinds and headwinds**, and a "funding pulse"
read of the deals tracked.

## How it works

```
discover URLs ──► fetch + parse articles ──► extract deal fields ──► dedupe ──► docs/data/*.json ──► website
(sitemaps, RSS,      (polite: robots.txt,       (Claude, or rules     (same company +
 funding listings)    1 req/s per site)          if no API key)        round ≤45 days)
```

**Coverage.** Each site is crawled through several channels so a gap in one is caught by another:

| Site | Channels |
|---|---|
| VIE Stories | daily sitemaps (`sitemap_YYYY-MM-DD.xml`, every article published that day), news sitemap, RSS, `/funding-alert?page=N` until older than the window |
| YourStory | sitemap indexes (main + AI, enterprise, SMB, HerStory, SocialStory sections), news sitemap, RSS, `/category/funding?page=N` |

Funding-alert articles on VIE Stories are always taken. Elsewhere, URLs are kept when the slug or
title looks like a funding announcement. Claude then rejects anything that isn't a single, Indian
company's funding round (roundups, IPOs, results, foreign companies). Each article's outcome is
counted per ISO week and source on the site's **Coverage** tab, so gaps are visible.

**Extraction.** With an `ANTHROPIC_API_KEY`, each article goes to Claude (`claude-opus-5-5` by
default, override with `TRACKER_MODEL`), which returns schema-validated JSON. Without a key, a
rules-based parser reads the standard headline format ("X raises $Y in Z round led by W") and
classifies sectors by keyword. Sector notes come with the repo and are regenerated by Claude
from the tracked deals when a key is set (when a sector is new, has grown by 5+ deals, or its note is older than 21 days).

## Running it

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # optional but recommended
python -m scraper.run --days 90          # first run: 3-month backfill
python -m scraper.run                    # weekly: since last run, with 7-day overlap
python -m pytest -q tests
```

Useful flags: `--sources viestories`, `--reprocess` (ignore the processed-URL cache),
`--refresh-insights`, `--max-pages 150`, `--workers 8`.

To preview the site locally: `cd docs && python -m http.server` and open http://localhost:8000.

## Hosting and the weekly schedule

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. **Settings → Secrets and variables → Actions → New repository secret:** `ANTHROPIC_API_KEY`.
3. **Actions → Weekly funding update → Run workflow** with `days = 90` for the first backfill.

After that, the workflow runs every Monday at 09:00 IST, commits the new data, and redeploys the site.

## Data files (`docs/data/`)

- `deals.json`: every deal, newest first
- `sectors.json`: sector briefs, tailwinds, headwinds, stats
- `coverage.json`: per-week, per-source counts and the last 60 runs
- `processed.json`: URLs already handled (so weekly runs only fetch new articles)
- `state.json`: last run time
